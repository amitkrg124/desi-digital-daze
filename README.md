# Kirana Nostalgia Corner

Build a complete, polished, single-page nostalgic website based on:
TOPIC: 2000s Kirana Store
MUSIC PLAYLIST: https://youtube.com/playlist?list=PLrc1-2uc6G7j--pBF0vbBxHvfI0gJhzdQ&si=K7G85ErJIq5mAwRX

First, understand the culture, memories, objects, colors, phrases, sounds, and visual aesthetic associated with the topic. Use those details to create an immersive experience rather than a generic website. Build everything as a single index.html file with embedded HTML, CSS, and JavaScript.

The website should include:
- A visually rich nostalgic background inspired by the topic
- A large memorable title matching the theme
- One strong central visual or illustrated object representing the topic
- Small authentic details, labels, status indicators, phrases, slang, quotes, or memories associated with it
- Rotating nostalgic quotes/messages that automatically change every few seconds
- A beautiful glassmorphism music player fixed near the bottom with play/pause, previous, next, track name, and progress, using the provided YouTube playlist as the website's music source
- One fun keyboard/click interaction with a sound or animation that makes sense for the topic
- Smooth transitions, subtle animations, hover effects, and responsive design
- Make it feel modern, minimal, cinematic, and deeply nostalgic. Avoid generic stock-website styling

Additional instructions from the user: use the same attached image as the website's background, and keep the UI looking like the attached reference image (layout/composition should stay similar). The UI should be in a red tone, 90s vibe, not an AI-style dual-tone color scheme. Reference website for the overall style: https://saloon.wtf/
## Development

```sh
git clone https://github.com/amitkrg124/desi-digital-daze.git
cd desi-digital-daze
npm i
npm run dev
```
